Banker's Algorithm Simulator — Interactive Deadlock Avoidance Visualization

รายวิชา CS422 Operating Systems — บทบาท: ออกแบบโปรเจกต์จำลองการทำงานระบบปฏิบัติการ (Academic Project) สมาชิก 5 คน

Course: CS422 Operating Systems — Role: Project Designer (Academic Project, Team of 5)

  • ออกแบบ UI และขั้นตอนการแสดงผลของเครื่องมือจำลองการทำงานของ Banker's Algorithm ซึ่งเป็นอัลกอริทึมสำคัญในการจัดการและหลีกเลี่ยงภาวะ Deadlock ในระบบปฏิบัติการ
  • ออกแบบส่วนติดต่อผู้ใช้ (UI) และหน้าแสดงผลขั้นตอนการคำนวณแบบ Interactive (Computation Steps Timeline) ครอบคลุมตาราง Allocation, Maximum, Need Matrix และ Available Resources
  • ออกแบบหน้าแสดงลำดับความปลอดภัยของกระบวนการ (Safe Sequence: P1 → P3 → P0 → P2 → P4) พร้อมสรุปสถานะความปลอดภัยของระบบ (Safe State Verification Table) อย่างชัดเจน
  • Designed the UI and display flow of an interactive simulation tool for the Banker's Algorithm, a crucial algorithm for managing and avoiding deadlock in operating systems
  • Designed the user interface (UI) and an interactive computation steps timeline covering the Allocation, Maximum, and Need matrices, as well as Available Resources
  • Designed the screen that shows the safe process sequence (Safe Sequence: P1 → P3 → P0 → P2 → P4) along with a summary of the system's safety status via a Safe State Verification Table

ผลลัพธ์: ทีมได้ Simulator ที่ช่วยให้ผู้ใช้งานเข้าใจหลักการทำงานเชิงลึกของ Deadlock Avoidance ในวิชา Operating Systems ได้อย่างเห็นภาพและใช้งานง่าย

Result: The team delivered a simulator that helps users clearly understand and easily grasp the in-depth working principles of deadlock avoidance in the Operating Systems course.

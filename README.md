# Portfolio เว็บของศรีรัตน์ (Srirat Intalai)

เว็บพอร์ตโฟลิโอส่วนตัว ทำตามไฟล์ดีไซน์ `ศรีรัตน์_อินทลัย.pdf` แบบง่ายๆ
ใช้แค่ HTML + CSS + JavaScript ธรรมดา ไม่มี framework ไม่ต้อง build อะไรทั้งนั้น

## วิธีเปิดดูเว็บ

ดับเบิลคลิกไฟล์ `index.html` เปิดด้วยเบราว์เซอร์ได้เลย (Chrome / Safari / Edge)

หรือถ้าอยากรันผ่าน local server (กันปัญหารูปโหลดไม่ขึ้นบางเครื่อง) ให้เปิด Terminal
แล้วรันคำสั่งนี้ในโฟลเดอร์นี้:

```
python3 -m http.server 8000
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

## โครงสร้างไฟล์

```
index.html          หน้าเว็บทั้งหมด (มีหน้าเดียว เลื่อนดูทีละส่วน)
css/style.css        ไฟล์สีและหน้าตาเว็บ
js/script.js         ไฟล์สั่งงาน ปุ่ม Enter, สลับธีม, สลับภาษา, สไลด์รูป, กรองใบรับรอง, ฟอร์ม
assets/              รูปโปรไฟล์ / รูปหน้าปก
images/              รูปโปรเจกต์ กับรูปกิจกรรม
certificates/        ไฟล์ใบรับรอง (รูปกับ PDF)
```

## ฟีเจอร์ที่ทำไว้

- หน้าปกกด Enter เข้าเว็บ
- สลับภาษาไทย/อังกฤษ ได้ทั้งเว็บ (ปุ่มมุมขวาบน)
- สลับธีมสว่าง/มืด ได้ (ปุ่มมุมขวาบน)
- เมนูมือถือ (แฮมเบอร์เกอร์)
- สไลด์รูปในหัวข้อ About Me (เปลี่ยนเองอัตโนมัติ + กดเลื่อนเองได้)
- กรองใบรับรองตามหมวดหมู่ + คลิกดูรูปขยาย
- ฟอร์มติดต่อ เช็คก่อนส่งว่ากรอกครบไหม

## ถ้าจะแก้ข้อมูล

ข้อมูลทุกอย่าง (ชื่อ, ประวัติ, โปรเจกต์, ใบรับรอง ฯลฯ) เขียนอยู่ตรงๆ ใน `index.html`
เปิดไฟล์นี้ด้วยโปรแกรมแก้โค้ด (เช่น VS Code) แล้วหาข้อความที่อยากแก้ แก้ตรงนั้นได้เลย
ไม่ต้องไปยุ่งกับไฟล์ css หรือ js ก็ได้ถ้าแค่จะแก้ข้อความ
